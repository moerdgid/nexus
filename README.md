
# Nexus

Nexus is a personal web dashboard for organizing frequently used websites, applications, and information in one place.

The goal is to create a clean, customizable homepage with categorized links, useful widgets, and integrations with personal services.

Nexus is part of **Fulcrum**, my broader self-hosted infrastructure project.

## Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Backend (planned):** C#, ASP.NET Core
- **Hosting (planned):** Oracle Cloud, Ubuntu Linux

## Getting Started

### Prerequisites

- Node.js
- npm
- Git


## Planned Features

- Customizable dashboard with categorized website links
- Search and navigation
- Weather, calendar, and news widgets
- Integration with personal applications and services
- Backend API and persistent data storage
- Authentication and secure remote access
- Fulcrum server monitoring and integration

## Development Status

**Early Development**

The initial React frontend is configured, and development of the dashboard's core components is underway.

Current priorities include building the main layout, implementing reusable link categories, and establishing the dashboard's visual design.

Backend development and server deployment will follow once the frontend foundation is established.

## Fulcrum

Fulcrum is the infrastructure environment intended to host Nexus and other personal services.

Nexus will serve as its web-based dashboard, providing a central interface for accessing information, applications, and eventually server management tools.
